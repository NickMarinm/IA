# GoalMatch

GoalMatch es un prototipo de comunidad de fútbol amateur para Bogotá y Medellín. Busca facilitar la organización de partidos y conectar a jugadores con partidos, canchas y arqueros. También propone herramientas para jugar y hacer seguimiento a cada encuentro, como equipos balanceados, marcador en vivo, votación al MVP y reconocimiento de la figura de cada equipo.

## Demo

La aplicación está publicada en [fo-kin12.github.io/goalmatch](https://fo-kin12.github.io/goalmatch/).

## Uso local

No se necesita instalar dependencias ni ejecutar un proceso de compilación: la aplicación está en [`index.html`](./index.html). Para probarla, descarga o clona el proyecto y abre ese archivo en un navegador moderno. Algunas funciones y recursos externos pueden requerir conexión a internet.

La demo es un prototipo y puede contener información o datos de ejemplo. No ingreses información sensible ni uses la aplicación para gestionar pagos reales.

## Otras actividades

Los siguientes ejercicios son trabajos académicos independientes y no forman parte de GoalMatch.

### Actividad: tres cupos

En [`actividad_tres_cupos.txt`](./documentos/actividad_tres_cupos.txt) se analiza cómo asignar tres cupos de acompañamiento entre ocho estudiantes. El documento compara decisiones tomadas con información general y conociendo las condiciones del programa, como los horarios flexibles y el acceso adicional a computadores. La actividad permite observar cómo el objetivo y los recursos disponibles cambian los criterios de selección.

### Ordenar tres números

En [`ordenar_tres_numeros.psc`](./documentos/ordenar_tres_numeros.psc) hay un algoritmo de PSeInt que solicita tres números enteros y muestra cuál es el mayor, el intermedio y el menor. Está planteado para valores distintos; con números repetidos puede no mostrar el resultado, porque las comparaciones usan `>` estricto.

Para más contexto sobre estos archivos y la presentación, consulta el [README de documentos](./documentos/README.md).
